# Marketing-Campaign-Analysis
SQL queries and Power BI dashboard for analyzing marketing campaign performance across channels, regions, and customer segments.


Marketing Campaign Analysis
Analyzed a marketing dataset of 1000 records to find what's working and what's not across campaigns, channels, and customer segments. Built SQL queries for all the metrics and visualized everything in Power BI.
Dataset

1000 rows, 24 columns
Covers 4 campaigns — New Year Sale, Winter Blast, Festive Rush, Mega Savings
Channels — YouTube, Google Ads, Instagram, Email
Has info on impressions, clicks, conversions, ROI, engagement, device, region, gender, age group, A/B test version

What I did

Cleaned the dataset
Wrote SQL queries to pull KPIs and chart data
Built a 2-page Power BI dashboard

Key Findings

New Year Sale had the highest conversions (76K)
Mobile drove the most conversions compared to Desktop and Tablet
Adult age group converted the most
YouTube had the highest conversion numbers among all channels
A/B test version A slightly outperformed B on most channels
